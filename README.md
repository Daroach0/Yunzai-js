# FX 战士久留美 · 拟股喵喵

> 基于 Yunzai-Bot 的双市场外汇模拟小游戏 · 单文件版
>
> 「老实赚钱很枯燥吧？要不要试试看，用 FX……把人生翻个面？」

## 项目简介

FX 战士久留美是一款运行在 Yunzai-Bot 上的**文字版外汇模拟交易游戏**。玩家通过猜汇率涨跌来赚取或亏损虚拟资金，体验外汇交易的刺激与残酷。

本仓库提供的是**单文件版**，一个 `.js` 文件放进去即可运行，无需额外依赖。后续会推出功能更完整的**插件包版**（带配置文件、Guoba 界面、图片渲染等）。

## 核心特性

### 双市场系统

| 市场 | 前缀 | 说明 |
|------|------|------|
| 独立场 | `#独` | 每人一份独立行情，群聊私聊都能玩，数据互通 |
| 共享场 | `#共` | 全群共用一份行情，仅限群聊，**过半人数投票即推进** |

两套行情下注用的是同一个钱包：独立场赚了 → 共享场可用余额增加；共享场亏了 → 独立场可用余额减少。爆仓判定按**总维持率 < 50%** 统一触发。

### 回合制推进

游戏采用回合制设计，每次推进一天，开牌后结算盈亏。

- **独立场**：`#独下一天` 推进自己的一天，`#独下10天` 可连推（最多 100 天），中途爆仓提前停止。
- **共享场**：`#共下一天` 或 `#共下N天` 投票，**达到活跃人数过半即推进**，取已投票人的最小天数。防止有人挂机导致全群卡死，同时保证最保守的人说了算。

### 9 种货币对

支持美日、欧美、镑美、澳美、美中、欧日、黄金、欧瑞、美瑞，每对货币有不同的价格精度和波动率。

### 4 档杠杆

| 别名 | 杠杆 | 爆仓线 |
|------|------|--------|
| 稳 | 5× | 逆向 20% 才爆 |
| 中 | 25× | 逆向 4% 才爆 |
| 梭 | 200× | 逆向 0.5% 才爆 |
| 疯 | 2000× | 逆向 0.05% 就没了 |

也支持直接输入数字（1~2000）。

### 丰富的游戏机制

- **爆仓（盘中触发）**：逐仓判定。使用当日 K 线的**最高价 / 最低价**触发（插针也会爆，不只看收盘）。单个仓位亏损 ≥ 保证金时自动爆掉，最多亏光保证金，不会穿仓
- **K 线图**：`#独K线 美日` 输出 SVG 蜡烛图，含开/高/低/收、当日振幅、实体涨跌幅，支持 `#共K线` 查看共享场
- **天台**：爆仓后 5 分钟内发送 `#天台` 可领取补助金
- **借钱加仓**：余额不足时借 ¥50,000，3 天内还清，否则日息累积
- **偷钱**：破产周期内唯一的一次暴富机会，50% 成功拿 ¥3,000,000；**若失败，没收所有余额，叠加 5 万罚款，且 24 小时内无法申请破产**。禁止带未还借款去偷钱
- **还赃**：偷钱成功后可用 `#还赃` 归还，不影响排行榜
- **个人破产**：欠债后申请，免除全部负债（含未还借款），余额重置为 ¥10,000。**历史破产免除的款项会累加到“老赖榜”**
- **B计划**：爆仓后 5 分钟内启动，把余额全部押上，一把定生死
- **打工**：4 小时一次，随机收入，有加班/彩蛋
- **盯盘**：每日一次，随机获得金钱或情报
- **NPC 系统**：久留美 / 萌智子 / 芽吹 / 安子，每次事件随机出现
- **黑天鹅事件库**：15 种事件随机触发，涵盖瑞郎脱钩、雷曼海啸、非农爆表、黄金避险潮、英国脱欧等，支持**局部货币对**与**系统性多货币对冲击**，避险品种自动反向（如雷曼时黄金暴涨）
- **情报系统**：盯盘获得的涨跌情报，下次独立场推进时生效
- **6 大排行榜 + 总榜**：富豪 / 股神 / 梭哈 / 韭菜 / 刺激 / 老赖
- **双榜机制**：每个榜分「本群榜」和「全服榜」
- **视奸**：查看别人的账户数据（净值/战绩/持仓），不显示对方独立场行情
### 游戏文案

内置 300+ 条角色台词和随机事件，涵盖开仓、爆仓、盈利、亏损、天台等各个场景，自动根据你的资金状况和操作风格切换对白。

## 安装

**前置要求**：Yunzai-Bot（TRSS-Yunzai / Miao-Yunzai 均可），Redis 可用。

1. 下载 `FX战士.js`（本仓库的 js 文件）
2. 放到 Yunzai 根目录下的 `plugins/example/` 文件夹里
3. 重启 Yunzai，或执行一次热重载


**验证**：在群里或私聊发送 `#拟股喵喵帮助`，如果收到回复，说明安装成功。

### 常见问题

- **收不到回复** → 检查文件名后缀是否为 `.js`，检查文件是否真的在 `plugins/example/` 下，看 Yunzai 日志有没有报错。。
- **私聊发详细帮助，bot 那边看不到自己发的文件** → 这是 QQ PC 客户端的已知显示 bug，对面能看到，切号/重启客户端也会出现，不是插件问题。
- **加仓提示杠杆不一致** → 这是设计如此。同一仓位只允许相同杠杆加仓，想换杠杆需要先平仓。

## 机制详解

### 独立场 vs 共享场

| | 独立场 | 共享场 |
|--|--------|--------|
| 行情 | 每人独立 | 全群共用 |
| 可用位置 | 群聊 + 私聊 | 仅群聊 |
| 推进方式 | 自由推进 | 过半投票 |
| 数据互通 | 群聊私聊同一份 | 群内共用 |

### 钱包共享

两套行情下注用的是同一个钱包：

- 独立场赚了 → 共享场可用余额增加
- 共享场亏了 → 独立场可用余额减少
- 爆仓判定：逐仓独立。每个仓位亏损 ≥ 自己的保证金时，单独爆掉
- 各仓位互不影响，一个爆了不会拖累其它仓位
- 爆仓最多亏光保证金，不会穿仓

### 共享场过半推进制

共享场采用**过半推进制**：活跃 N 人时，需要 `floor(N/2)+1` 票才能推进。达到门槛立即开牌，取已投票人里的最小天数。

> **温馨提示**：共享场是「共进退」的，行情全群共用一份。只要过半群友投了票，就算你没投，也会被推进——这是回合制的兜底，最多被推几天，不会「天塌」。但持仓期间还是建议常回群看看，忙就发 `#退出共享`，回来再 `#加入共享`。
> 另外，爆仓后如果两个场都空仓，会自动从活跃名单移除，不用手动退。

举例（活跃 4 人，需要 3 票）：

- A 投 1，B 投 5，C 投 3 → 立即推 **1** 天
- D 没投 → 也会被推进 1 天

### 偷钱与老赖的闭环

濒临破产（余额 < ¥10,000）时的最后手段。

- **每个破产周期只有一次机会**（不能有未还借款）
- **成功**：+¥3,000,000（待还赃 +300 万）
- **失败**：强制平仓，**没收所有余额**，强制叠加 **¥50,000 罚款**，且**锁定 24 小时无法申请破产**。原有债务与罚款合并，玩家将陷入死局。

**老赖榜的折磨**：
如果偷钱失败后，玩家熬过 24 小时，依然无力偿还高额债务，被迫发送 `#个人破产`。此时，那笔被免除的巨额债务会永久累加到 `totalUnpaidDebt` 字段，并展示在**老赖榜**上。就算日后外汇翻本，老赖榜的记录也永远不会消除。

**榜单影响**：

- 偷钱成功 → 刺激榜 +300 万
- 偷钱失败 → 平仓后如果有债务 → 老赖榜累加
- 还赃 → 只扣余额，**不影响任何榜单**
- 偷钱**不进**股神榜 / 韭菜榜（非外汇）

### 排行榜说明

**双榜机制**：所有榜单分「本群榜」和「全服榜」。

- 本群榜：只统计当前群的玩家，每个群一份独立榜单
- 全服榜：所有群所有玩家混合排名
- 私聊没有本群概念，`#富豪榜` 会自动落到全服榜
- 玩家换群、加群时，本群榜需要重新触发一次（发任意指令即可加入本群榜）

**榜单口径**：

| 榜单 | 统计口径 |
|------|---------|
| 富豪榜 | 当前余额 |
| 股神榜 | 外汇交易净盈利（平仓 / 爆仓时统计） |
| 梭哈榜 | 累计投入金额 × (1 + 最大杠杆/100) |
| 韭菜榜 | 外汇交易净亏损 |
| 刺激榜 | 外汇绝对盈亏和 + 偷钱金额 |
| 老赖榜 | 破产 / 偷钱失败时被免除的负债累计 |

**数据同步**：玩家每次保存账号时，会同时写入「全服榜」和「当前群的本群榜」。私聊操作只写全服榜。

**主人指令**：`#重建排行榜` 可强制重建全服榜（群榜由玩家操作自然填充）。

### 走势图说明

```
⇈ 大涨 ↗ 小涨 → 平 ↘ 小跌 ⇊ 大跌
```


### 黑天鹅事件库

每次 `#下一天` 推进，都会以约 2% 的概率随机抽取一个黑天鹅事件。共有 **15 种事件**：

- **单货币对事件**：黄金避险潮（+5%~15%）、央妈出手（美中-3%~10%）、澳央行降息、EUR/JPY 闪崩等。
- **局部组合事件**：瑞士央行放弃下限（欧瑞/美瑞 -15%~30%）、非农爆表、英国脱欧、黑色星期一、日元套息崩溃等。
- **系统性事件**：
  - **雷曼海啸**：全部 9 个货币对暴跌（-3%~12%），**黄金反向暴涨**（+3%~12%）。
  - **美债上限危机**：美日、美中暴跌，**黄金反向上涨**。

> 事件产生的跳空会写入当日 K 线，爆仓判定会直接触发。哪怕你方向押对了，也可能被避险品种的反向波动带走。

### NPC 系统

每次关键事件（开仓 / 加仓 / 平仓 / 爆仓 / 打工 / 盯盘 / 借钱 / 天台 / 偷钱 / 领补助）时随机抽一位 NPC 出来说句话。

| NPC | 风格 | 特点 |
|-----|------|------|
| 久留美 | 激进 | 连亏时鼓励加注，梭哈时欢呼，天台偶发地狱梗 |

## 设计说明

一些玩家经常问到的设计问题，集中在这里回答。

### 为什么不叫股票，叫外汇？

核心玩法决定了它是外汇，不是股票：

- **可以做空**：`#押跌` 是核心玩法之一。A 股散户想做空要开两融，不是普通操作。
- **高杠杆**：最高 2000×。"疯"档逆向 0.05% 就归零——这是外汇零售平台才有的刺激，股票和期货都到不了。
- **货币对**：美日涨不代表日元跌，而是"美元相对日元变强"。这是相对关系，不是单一标的。
- **互相参照**：9 对货币在逻辑上互相约束（美日、欧美、镑美…），股票做不到。

回合制和统一计价是为了适配群聊场景做的简化，不是外汇本身的特征。

### 为什么是回合制，不是 T+0？

游戏是**回合制**：价格只在 `#下一天` 时变动。

- 玩家开仓 → 当前价 P₁
- 不推进就平仓 → 还是 P₁
- 结果：**盈亏 = 0**，相当于撤单

技术上已经是"随时可平"，但价格不实时变动。这是为了：

- 不用定时任务实时 tick
- 一个人也能玩，不用等行情
- 适合群聊场景（大家一起点"下一天"）

真要"真 T+0"，需要每分钟 tick、实时推送、日内手续费、点差滑点——那是另一个游戏，不是这个。

### 汇率之间会不会存在价差？

理论上会。9 对货币对**独立随机波动**，所以 `EURJPY` 不一定等于 `EURUSD × USDJPY`，存在交叉汇率不一致。

但实际上赚不到：

- **开仓不是换汇**，是押方向，玩家无法真的兑换货币
- **回合制**：开仓和平仓之间必须经过 `#下一天`，那一天所有价格会重新波动
- **独立保证金**：做 3 个仓位要 3 份保证金
- **每次 tick 都是新随机**，没有"回归机制"，无法赌差价收敛

玩家打开行情看到的不一致只是"心理感受"，“赚差价”赚不到钱。

> 顺便纠正一下，群友提到的"蒙代尔-弗莱明不可能三角"是讲**货币政策**的（资本流动、固定汇率、独立货币政策三者不可兼得），和这里说的**交叉汇率一致性**不是同一件事。

### 为什么所有交易都用人民币结算？

游戏统一用 `¥` 计价。所有外汇盈亏都折算成人民币直接进账户。

这和**真实零售外汇平台的做法一致**：你开户时选一个账户基准币种（USD 或 CNY），之后所有交易盈亏都自动折算成该币种结算，平台内部做多币种账本，对玩家透明。

真做"多币种钱包"复杂度会爆炸：多币种账本、跨币种兑换、爆仓时各币种合并判定…对一个文字模拟游戏来说是过度设计。
